# Power BI Dashboard

## Sales & Order Management Analytics Dashboard

The Power BI dashboard provides an interactive view of sales, orders, customers, products, and payment performance.

## Dashboard Pages

### Page 1 - Sales & Order Management Analytics Dashboard

This page contains:
- Total Sales Amount
- Total Orders
- Total Customers
- Sales Trend
- Sales by Year
- Quantity by Product
- Order Status Distribution

### Page 2 - Customer & Product Analysis

This page contains:
- Customer Performance
- Payment Status Analysis
- Product Category Analysis
- Customer and Order Details

### Page 3 - Sales Performance Summary

This page contains:
- Total Sales
- Total Orders
- Total Customers
- Order Status Distribution
- Sales Amount by Order Status

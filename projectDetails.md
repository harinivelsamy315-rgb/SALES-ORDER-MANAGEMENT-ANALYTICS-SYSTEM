# Sales & Order Management Analytics System

## Project Overview

The Sales & Order Management Analytics System is a data analytics project developed to analyze customer orders, products, payments, sales performance, and business trends.

The project uses MySQL for database management and Power BI for data visualization and dashboard reporting.

## Objectives

- Store customer, product, order, order item, and payment information.
- Perform SQL-based data analysis.
- Analyze sales and order performance.
- Identify customer and product performance.
- Generate monthly sales insights.
- Create an interactive Power BI dashboard.
